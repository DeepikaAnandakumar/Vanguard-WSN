# Vanguard-WSN: Final Honest Results Dataset

This directory contains the single source of truth for the simulation results presented in the final manuscript.

## Dataset Overview
- **File**: `results_50nodes.json`
- **Rigorous Verification**: 10 random seeds per algorithm.
- **Algorithms Included**:
    - `Baseline_deterministic`: Standard LEACH (Deterministic).
    - `EBPT_Gamma_0.5`: Static energy-balanced routing.
    - `Adaptive_balanced`: Dynamic routing with adaptive weighting.
    - `Hybrid_AllFeatures`: Fully optimized Vanguard-WSN (EBPT-CRA).

## Key Metrics Captured
- **First Node Death (FND)**: Round counts for stability tracking.
- **Cumulative Throughput**: Real packet delivery logs (no approximations).
- **Per-Node Energy Snapshots**: Captured at Round 100 for spatial heatmap generation.
- **Node Positions**: Real placement coordinates for topology snapshots.

## Performance Highlight
- **Vanguard-WSN (Hybrid)** achieves **993.1 Rounds (FND)**.
